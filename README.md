# NdeyeDid AI

## Overview

NdeyeDid AI is an AI-powered receptionist and business automation system for my braiding business.

The goal is to automate:

- Responding to DMs
- Pricing questions
- Booking appointments
- FAQs
- Appointment reminders
- Review requests
- Rebooking clients

## Tech Stack

- ChatGPT
- Claude
- GitHub
- n8n (coming soon)
- Google Calendar
- Google Forms
